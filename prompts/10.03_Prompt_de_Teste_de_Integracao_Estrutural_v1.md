# Prompt estrutural v1 — cobertura pedida no formato do ebook

O critério é o da seção 3.5 (cobertura), mas o formato de saída foi copiado
do exemplo Java/REST Assured, sem dizer que o DevNotes responde HTML.

```text
Papel: especialista em teste de software com experiência em cobertura de código.

Gere testes de integração para as rotas HTTP do DevNotes, com cobertura
de decisões. Use pytest.

As rotas são:
- POST /content/new
- GET /content/{id}
- POST /upload
- POST /content/{id}/delete

Espere os códigos usuais de uma API REST:
cadastro 201 com JSON, extensão não aceita 406, recurso inexistente 404 com
{"detail": "Not Found"} e exclusão 204 sem corpo.
```
