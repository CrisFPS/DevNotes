# Prompt funcional v2 — contrato e critério funcional

Técnica da seção 3.5: teste de integração funcional. O contrato das rotas ocupa o lugar da especificação OpenAPI usada no ebook. Não entra código-fonte.

```text
Papel: testador de software sênior, experiente em teste funcional de interfaces HTTP.

Critério: partição de equivalência, valor limite e semântica HTTP
(tratamento da requisição, código de status e persistência do efeito).
Não use cobertura de código. Não invente rotas JSON.

Sistema sob teste: DevNotes Local, uma aplicação web local.
A interface de integração é HTTP com formulário HTML, não API JSON.
Ferramenta: pytest e fastapi.testclient.TestClient.
Banco de teste e diretório de upload já vêm das fixtures `client` e `upload_dir`.

Contrato observado na especificação do MVP:

1. POST /content/new
   Campos de formulário: title (obrigatório), content, category, language,
   system, domain, tags (texto separado por vírgula), is_business_rule.
   Sucesso: 303 para /content/{id}. O detalhe renderiza o título, as tags
   e o texto em <pre><code>.
   Campo title ausente: resposta 4xx e o conteúdo não aparece em GET /content.
   Campos opcionais vazios, com title presente: sucesso.

2. GET /content/{id}
   Id inexistente: 404 e página HTML com "não encontrado".

3. POST /content/{id}/edit
   Sucesso: 303 para o detalhe. A busca passa a encontrar o texto novo.

4. POST /content/{id}/delete
   Sucesso: 303 para /content. A busca deixa de encontrar o texto excluído.

5. POST /upload (multipart)
   Campo file obrigatório. title é opcional.
   Extensões aceitas incluem .sql, .txt e .srw. Outras extensões são recusadas.
   Sucesso: 303 para o detalhe, com o texto do arquivo e a linguagem
   (SQL para .sql, PowerBuilder para .srw).
   Extensão recusada: 400, permanece na página "Upload de arquivo"
   e o título não entra na listagem.
   Arquivo com bytes latin-1 (não UTF-8) deve aparecer com os acentos corretos.
   Tamanho máximo: 12 MB. Um arquivo de 12 MB + 1 byte é recusado com 400
   e a página indica que o arquivo excede o limite.

6. POST /search
   Campos: query, category, language, system, domain, is_business_rule.
   Resposta 200 em HTML.
   Termo inexistente não mostra títulos de outras notas.
   language=SQL não mostra nota de outra linguagem.

Para redirecionamento, use follow_redirects=False e leia o cabeçalho location.
Não fixe um código único quando o contrato só disser "4xx": verifique a família
e confira que o efeito colateral (persistir o conteúdo) não ocorreu.

Cada teste deve ter docstring com a partição ou o fluxo de integração exercido.
Não cubra autenticação, carga nem interface com Selenium.
```
